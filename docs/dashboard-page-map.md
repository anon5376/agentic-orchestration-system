# AOS dashboard page map

Status: visual-comp scope. Page names and navigation labels are provisional.

1. **Missions** — investigations across projects, their state, unresolved decisions, and recent activity.
2. **Goal Intake** — prompt and document intake, interpreted objective, scope questions, and effective execution policy before launch.
3. **Live Swarm** — the active hierarchy and dependency field, branch traffic, selected agent detail, intervention, pause, and CLI drawer.
4. **Evidence Atlas** — claims, hypotheses, sources, contradictions, confidence, missing evidence, and original artifacts.
5. **Synthesis Gate** — the lead agent's proposed conclusion, independent checks, unresolved objections, and the decision to continue or complete.
6. **Evolution** — run retrospective, diagnosed failures, proposed changes, controlled comparison, adoption, rejection, and rollback.
7. **Capabilities** — worker harnesses, models, skills, plugins, MCP servers, generated tools, authentication, availability, and limits.
8. **Memory & Policies** — global, project, and agent memory; retention; context inheritance; permissions; improvement policy; audit history.

All pages share one run state and stable identifiers. The CLI is a peer interface and can also appear as an optional drawer inside the dashboard.
