## Rules for every task

- One task at a time per owner, in board order. A task is done when its evidence is posted on the bus under `[AOS-BUILD]` and Fable replies "accepted".
- Evidence means: the exact paths changed, the diff stat, the full `npm test` summary block (tests, pass, fail counts) pasted verbatim from the run, the names of the new tests, and any command output the acceptance column asks for. "Tests pass" without the block is not evidence.
- Touch only the paths listed for the task. If a fix needs another file, stop and say which file and why before editing it.
- No new production dependency. Test-only helpers go in `tests/`.
- A red test caused by the task stops the task; post the failure verbatim.
- Do not commit. After S0.2 the working tree is staged as a baseline so later changes are reviewable with `git diff --stat`.
