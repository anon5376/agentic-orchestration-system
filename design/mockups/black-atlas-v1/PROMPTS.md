## Shared prompt

Create a high-fidelity, edge-to-edge 16:10 desktop dashboard for AOS, an open-source system that coordinates hierarchical agent swarms for difficult research. Use the Black Atlas world: absolute black, chalk white, fluorescent vermilion, and limited ash grey; a broken-arc AOS sigil; a razor-thin global rail; monumental condensed grotesk headings; neutral sans body text; compact monospace telemetry; square corners; interrupted borders; original dithered faceless scientific specimens; flat depth; and distortion caused by real system state.

Keep the interface operationally legible. Avoid permanent conventional sidebars, rounded card grids, gradients, glass, shadows, blue or purple, pill buttons, generic neon node graphs, mythological deities, hand-and-orb imagery, Nous or Hermes branding, copied compositions, fantasy concept art, and watermarks. Include a compact CLI drawer handle.
